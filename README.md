# Niya — Skin Atelier

Адаптивний лендінг російською та турецькою приватного косметолога. Vanilla JS, Vite і Three.js.

## Запуск

```sh
npm install
npm run dev
```

Скляна WebGL-скульптура, scroll-driven 3D-сцена, RU/TR перемикач, TRY-прайс, форма заявки та портрет Niya.
